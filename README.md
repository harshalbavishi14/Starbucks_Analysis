# ☕ Starbucks Beverage Analysis Dashboard

> **Interactive Power BI Dashboard for Nutritional Analysis of Starbucks Beverages**

![Dashboard Preview](Assets/dashboard.png)

---

## 📖 Project Overview

The **Starbucks Beverage Analysis Dashboard** is an interactive Business Intelligence project developed using **Microsoft Power BI**. The dashboard analyzes Starbucks beverage nutrition data to provide meaningful insights into calories, caffeine, sugar, protein, and beverage categories.

The objective of this project is to transform raw nutritional data into an intuitive and interactive dashboard that enables users to compare beverages, identify nutritional trends, and make data-driven decisions.

---

## 🎯 Business Objective

The primary goals of this project are to:

- Analyze nutritional information across Starbucks beverages.
- Compare calories, sugar, caffeine, and protein levels.
- Identify high-caffeine beverages.
- Explore beverage category distribution.
- Build an interactive dashboard for business reporting and analysis.

---

## 📊 Dashboard Features

### 📌 Key Performance Indicators (KPIs)

- ☕ Total Beverages
- 🔥 Average Calories
- ⚡ Average Caffeine
- 🍬 Average Sugar

### 📈 Visualizations

- Average Calories by Beverage Category
- Average Caffeine by Beverage Category
- Beverage Category Distribution
- Top 5 Highest Caffeine Beverages
- Interactive KPI Cards
- Dynamic Slicers & Filters

---

## 🎛 Interactive Filters

The dashboard allows users to explore data dynamically using:

- Protein Range Slider
- Beverage Preparation Filter
- Cross-filtering between visuals

---

## 📂 Dataset Information

The project uses two datasets.

| Dataset | Description |
|----------|-------------|
| **starbucks_nutrition.csv** | Beverage nutritional information including calories, caffeine, sugar, protein, carbohydrates, and beverage category. |
| **store_directory.csv** | Starbucks store information used for additional business analysis. |

## 📌 Key Insights

- Coffee-based beverages contain the highest average caffeine.
- Beverage categories vary significantly in calorie and sugar content.
- Frappuccino beverages generally contain higher sugar levels.
- Interactive filters allow quick comparison across beverage categories.
- The dashboard provides a clear overview of Starbucks beverage nutrition.
